# Tight handbook

These documents explain the **implemented** v1 game in this repository. They are written so someone can understand Tight without first reading sixty design files.

Start with the [repository README](../README.md), then:

| # | Document | Read it for |
|---:|---|---|
| 1 | [How to play](./how-to-play.md) | Keys, HUD, inventory, seeds, death, victory |
| 2 | [Universe](./universe.md) | 16 dimensions, 120 planes, transitions, pursuit |
| 3 | [Systems](./systems.md) | Tick, combat math, statuses, items, AP |
| 4 | [Generation](./generation.md) | How a seed becomes a proven, playable world |
| 5 | [Architecture](./architecture.md) | Code layout, core vs browser, tests |

If a handbook sentence disagrees with the design specifications in the `docs` repo (`projects/tight/`), the specification wins.
